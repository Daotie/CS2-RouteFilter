# Code of Conduct / 行为准则

RouteFilter contributors and community participants are expected to communicate professionally, assume good intent, and focus criticism on ideas and technical outcomes rather than individuals.

Harassment, discrimination, threats, deliberate disruption, publication of private information, and other conduct that makes participation unsafe are not acceptable. Maintainers may edit or remove contributions and restrict participation when necessary to protect the project community.

Report conduct concerns privately through the repository owner's GitHub profile. Reports will be reviewed in confidence and addressed proportionately.

RouteFilter 贡献者和社区参与者应保持专业沟通、善意理解，并将批评集中于方案和技术结果，而不是个人。

骚扰、歧视、威胁、蓄意干扰、公开他人隐私，以及其他危害参与安全的行为均不可接受。为保护项目社区，维护者可在必要时编辑或移除内容并限制参与权限。

行为问题请通过仓库所有者的 GitHub 个人资料进行私下报告。报告将被保密审查并得到适当处理。
