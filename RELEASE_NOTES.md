# RouteFilter 2.0.1

## English
- Added directional entry restrictions for both road Nodes and Segments. Choose which approaching entries use the target's forbidden asset list.
- Added optional physical roadside restriction signs, automatic theme selection and a compact custom prefab selector with native thumbnails and names.
- Improved sign facing and divider placement; the prefab selector opens beside the panel with bounded scrolling.
- Existing per-prefab enforcement and city-save restriction configuration remain unchanged.

### Known limitation
Some vehicles may still be missed by restriction detection and pass through a restricted target. Investigation will continue.

## 简体中文
- 新增道路节点与路段的入口方向限制，可选择哪些进入方向使用目标的禁止资产列表。
- 新增可开关的实体道路禁行标志、自动主题匹配及带原生缩略图和名称的紧凑自定义 prefab 选择列表。
- 调整标志朝向与分界线放置位置；选择列表在面板旁展开，限制高度并支持滚动。
- 保持原有逐资产禁行逻辑和城市存档禁行配置语义。

### 已知限制
禁行检测仍可能漏掉部分车辆，使其通过受限目标，后续将继续调查。
