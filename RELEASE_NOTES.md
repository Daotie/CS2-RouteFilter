# RouteFilter 2.1.0

## English

- Fixed the missed-vehicle restriction issue.
- Expanded the vehicle asset library with category checkboxes, collapsible groups, prefab thumbnails, favorites and recent assets.
- Added cross-target copy/paste, saved presets and goods-only truck / cargo-truck presets.
- Added batch application for road and rail segments: left mouse applies restrictions, right mouse clears them.
- Added a restriction map with land/water background, road and track geometry, restricted nodes/segments and cursor-centered zoom. Entry navigation markers scale with the network.
- Added persistent traffic-sign controls, EU/US styles and real-time position/rotation editing; mouse wheel adjusts only the hovered input using the selected step.
- Corrected supplementary plate rendering and localized text. Restricted/Except semantics choose a concise equivalent description on one plate, with at most two lines; full Other-category allowance reads 其它车辆除外 in Simplified Chinese.
- Existing city-save restriction data remains compatible. No new save schema or migration is introduced by this release.

## 简体中文

- 修复禁行漏车问题。
- 扩展车辆资产目录：分类复选框、分组展开、预制件图标、收藏与最近使用。
- 支持跨目标复制粘贴、保存预设，以及仅含货运资产的货车／货运货车预设。
- 加入道路与轨道路段批量应用：左键应用禁行，右键清除。
- 加入限行地图，显示陆地／水域、道路／轨道、受限节点与路段，并支持朝光标缩放；入口导航箭头随路网缩放。
- 加入常驻交通标志面板、EU／US 样式和实时位置／旋转调整；滚轮仅修改悬浮输入框，并使用选定步长。
- 修正辅助牌材质与本地化文字，比较禁止对象和除外对象，合并为一块辅助牌、最多两行；整类其它车辆允许时正确显示“其它车辆除外”。
- 沿用既有城市存档禁行数据，正式版不引入新的存档格式或迁移。
