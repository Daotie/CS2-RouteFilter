# Changelog / 更新日志

## 0.1.0-beta.1 — 2026-08-19

### English

- First public-code beta of NodeGate.
- Added exact selection for 20 road, rail, bicycle, and city-service vehicle types.
- Added a top-left in-game button and vehicle selection panel.
- Added automatic English/Simplified Chinese localization.
- Added save serialization and configurable enforcement behavior.

### 中文

- NodeGate 首个代码开源 Beta 版本。
- 新增 20 种道路、轨道、自行车及市政服务车型的精确选择。
- 新增游戏左上角按钮和车型选择面板。
- 新增英文/简体中文自动本地化。
- 新增随存档保存和可配置拦截行为。
