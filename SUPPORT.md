# Support / 支持

## Before opening an issue

1. Confirm the issue occurs with the latest RouteFilter release.
2. Back up the save and test with the smallest practical mod set.
3. Check existing issues for duplicates.
4. Collect the game version, RouteFilter version, active playset, reproduction steps, and `Player.log`.

Use the bug report template for defects and the feature request template for proposals. General Cities: Skylines II modding or game-support questions should be directed to the appropriate community or official support channel.

## 提交问题前

1. 确认问题可在最新 RouteFilter 版本复现。
2. 备份存档，并尽可能使用最小模组集合测试。
3. 检查是否已有重复 Issue。
4. 准备游戏版本、RouteFilter 版本、当前播放集、复现步骤和 `Player.log`。

缺陷请使用 Bug 模板，建议请使用功能请求模板。与 RouteFilter 无直接关系的游戏或通用模组问题，请前往对应社区或官方支持渠道。
