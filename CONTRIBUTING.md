# Contributing / 参与贡献

English first for wider discovery; Chinese follows below.

Open an issue before large changes. Keep commits focused and use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`). Build both C# and UI before submitting a pull request. By contributing, you agree that your work is licensed under GPL-3.0.

大型改动请先创建 Issue。提交应保持聚焦并使用 Conventional Commits（`feat:`、`fix:`、`docs:`、`test:`、`chore:`）。提交 PR 前请同时构建 C# 与 UI。参与贡献即表示同意以 GPL-3.0 发布贡献内容。
